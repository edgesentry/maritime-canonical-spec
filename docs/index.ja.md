# EdgeSentry `maritime-canonical-spec`

**EdgeSentry** プロジェクトのドキュメントです。対象リポジトリは `maritime-canonical-spec` — 海運・港湾物流・海上保険向けの国際標準準拠 **canonical data model** です。

本サイトは [edgesentry/maritime-canonical-spec](https://github.com/edgesentry/maritime-canonical-spec) の公開バイリンガルドキュメントです。国別・プラットフォーム固有の EDI マッピングはコアモデルの外に置きます。

## パッケージのインストール名

npm パッケージのインストール識別子は `@maritime-ai/canonical-spec` です。プロジェクトのアイデンティティは **EdgeSentry → maritime-canonical-spec** です。

```bash
pnpm add @maritime-ai/canonical-spec
```

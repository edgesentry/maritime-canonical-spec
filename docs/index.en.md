# EdgeSentry `maritime-canonical-spec`

**EdgeSentry** project documentation for `maritime-canonical-spec` — an international standards-compliant **canonical data model** for maritime shipping, port logistics, and marine insurance.

This site is the public, bilingual documentation for the [edgesentry/maritime-canonical-spec](https://github.com/edgesentry/maritime-canonical-spec) repository. Country- or platform-specific EDI mappings stay outside the core model.

## Package install name

The npm package install identifier is `@maritime-ai/canonical-spec`. Project identity remains **EdgeSentry → maritime-canonical-spec**.

```bash
pnpm add @maritime-ai/canonical-spec
```

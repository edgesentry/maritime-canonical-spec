# Security Policy

## Supported Versions

Security updates are provided for the latest published release line of `@maritime-ai/canonical-spec`. Pre-1.0 releases may include breaking changes; upgrade to the newest patch on the current minor when available.

| Version | Supported |
| ------- | --------- |
| 0.x     | Yes       |
| < 0.x   | No        |

## Reporting a Vulnerability

Please report security issues privately through [GitHub Security Advisories](https://github.com/edgesentry/maritime-canonical-spec/security/advisories/new) for this repository.

Do **not** open a public issue for vulnerabilities that could affect package consumers.

You can expect:

- An initial acknowledgement within **7 days**
- A status update within **14 days** (accepted, declined, or needs more information)
- Coordinated disclosure timing if a fix is required

If the report is accepted, we will work on a fix, publish a patched release when appropriate, and credit reporters who wish to be named. If declined, we will explain why (for example: not reproducible, out of scope, or already addressed).
